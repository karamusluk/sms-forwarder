# Code of conduct

Be respectful. Critique the change, not the person. Harassment, personal attacks, and posting someone else's private messages are not welcome.

This app can see SMS contents. Never paste a real message, a one-time code, or another person's email into an issue, pull request, or discussion.

Report a conduct problem through [GitHub private vulnerability reporting](https://github.com/karamusluk/sms-forwarder/security/advisories/new) and say it is a conduct report. Maintainers may edit or hide posts that include private message contents.
